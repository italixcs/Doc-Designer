# Document review

Use before delivering visually important artifacts. Keep notes outside the final document.

## Integrity

Inventory required sections/objects before redesign. Check them afterward, including captions, tables, headers/footers, notes, drawings, citations, values, units, code indentation, and symbols. Extraction helps comparison but does not prove visual fidelity or reading order.

Do not silently accept revisions, strip comments, flatten forms, or remove attribution. Resolve the intended final/review state from the request.

## Visual pass

1. Review a contact sheet for count, rhythm, density, and accidental blank pages.
2. Inspect every page at readable size, including top/bottom edges, dense tables, code, equations, labels, and footnotes.
3. Follow the reader's path and diagnose isolated headings, unexplained figures, and abrupt section changes.
4. Compare repeated components and repair underlying styles for recurring defects.
5. Check the last page for stranded lines and tiny fragments.
6. Re-export after meaningful changes; inspect affected pages and downstream pagination. Deliver matching file revisions.

Review long documents in batches. If limits prevent complete inspection, state actual scope rather than calling a sample complete.

## Usability and access

Check semantic headings, lists, links, captions, language, table headers, alternative text, and sensible reading order. Meaning must survive removal of color. Inspect grayscale for print/photocopy. Check captions and notes at real page size.

Measure contrast where useful. Contrast ratios do not certify a whole document. Selectable text does not prove correct PDF tagging. Use appropriate dedicated validation when conformance is requested.

Verify actual font availability/substitution and embedding where needed; XML naming a font is not proof. Check link destinations and private share tokens.

## Public samples

Use purpose-written fictional or public-domain content. Review visible content, comments, revisions, properties, custom properties, image metadata, embedded object names, source paths, and filenames. Preserve intentional copyright notices. Never publish private input as a demonstration.

Before/after comparisons use identical source content, paper size, and comparable crop/scale. Label deliberately basic baselines as demonstration fixtures; do not imply a controlled superiority study from staged images.

## Completion record

Record actual authoring route and renderer, pages inspected, content checks, unresolved limits, and final file identity when publishing evidence. Do not invent scores or universal viewer support.
