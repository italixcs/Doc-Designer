# Borrow a tool

A quick guide to the fictional Northbank Tool Library

## Opening hours

Wednesday: 16:00–19:00. Saturday: 10:00–13:00.

## Join and borrow

Membership is free. Ask at the desk to join. Members may borrow one item at a time.

Choose an available tool. The desk records the item and its return date. Check the return date before leaving.

## Loan periods

| Item | Loan period | Included |
| --- | --- | --- |
| Cordless drill | 7 days | Drill, battery, charger |
| Hand saw | 14 days | Saw and blade cover |
| Repair kit | 7 days | Kit and contents checklist |

## Return your tool

Bring the item back during opening hours. Return it clean and with all included parts.

If you expect to be late, contact the desk before the return date.

## Before you leave

Check the return date before leaving.
