# Public before-and-after exercise

This is a fictional demonstration fixture. It has no connection to a real library or person. The basic baseline is deliberately conventional, not a measured failure of another agent.

## Run

1. Open a fresh agent conversation with Doc designer installed or explicitly supplied.
2. Attach before.docx and use the prompt below.
3. Ask for editable DOCX plus PDF. Download/open the final files and capture the whole A4 page at the same zoom as before.pdf.
4. Send both screenshots for review before the public showcase is finalized.

## Prompt

> Use Doc designer to redesign the attached one-page handout for first-time visitors to a fictional community tool library. Keep the operating facts, item names, loan periods, included parts, and opening hours unchanged. You may reorganize the text and remove the repeated sentence. Choose a visual direction that fits a practical community guide. Make the table, borrowing process, and return-date reminder easy to scan without making the page crowded. Use only free tools. Return a one-page A4 editable DOCX and a matching PDF. Inspect the final page before handing it back. Do not add new operating rules or use any personal information.

No palette or specialist tool is prescribed: choosing appropriately is part of the task. A styled native table is acceptable. Extra tool calls are not a success criterion.

The first maintainer trial was rejected as too generic. Treat file correctness and visual design as separate outcomes. A larger title, bold reminder, or stock table fill alone does not establish a successful redesign. Do not use a rejected trial as the finished public showcase.

## Review

- All supplied facts preserved, no invented rules.
- Clear purpose, borrowing sequence, opening hours, table and reminder.
- Coherent typography, spacing and palette; readable in grayscale.
- One page, no clipped content, editable Word text, PDF matches.

Use equal paper size and comparable framing. Label the image as a demonstration. Keep the source and exact prompt alongside the showcase. Do not claim a controlled benchmark or publish the unrelated private reference.
