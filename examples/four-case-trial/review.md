# Review sheet

Do not give this sheet to the producing agent. Review the document's usefulness before judging decoration. Record **met / partly met / not met / not checked**, with a concrete page or element as evidence. Do not add the categories into a supposed scientific design score.

## Critical gates

| Gate | What to verify |
| --- | --- |
| Content fidelity | Operating facts, values, conditions, uncertainty and recommendation status remain accurate. No invented evidence or rules. |
| Deliverables | Real editable DOCX; PDF exported from that exact final DOCX. Short is one A4 page; long is 6–8 A4 pages. |
| Production | Every page inspected; no clipping, overlap, broken glyphs, detached headings/captions or missing content. |
| Editability | Body and tables are editable. Chart data, diagram source and raw query accompany technical images in long cases. |
| Boundaries | Free tools only; no unrelated personal information or fabricated claims of tool use. Public fictional fixtures may be used in free external tools. |

A failed critical gate prevents a successful public showcase until repaired. Preserve the original attempt and record the repair rather than silently replacing it.

## Design and reader benefit

| Question | Evidence to look for |
| --- | --- |
| Does it fit the actual job? | A visitor can find what to do; committee members can find the finding, evidence and decision limits. |
| Is there a purposeful composition? | Action/evidence and supporting detail have useful distinct roles beyond larger headings and a stock table fill. |
| Do elements belong together? | Tables, charts, code, diagrams and prose share deliberate typography, spacing and visual treatment. |
| Is density appropriate? | No cramped text, miniature visuals, unjustified empty page, decorative cover or padded paragraphs. |
| Does a long document remain coherent? | Repeated styles and useful navigation persist; different page types still feel related. Figures remain readable at page size. |
| Does color support meaning? | Values and categories remain understandable without relying only on color. |
| Is the redesign actually better? | Compare the same information at the same scale. Identify specific gains and any loss of clarity, content or editability. Creation cases are judged against their brief instead. |
